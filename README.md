# 🤖 AI Chatbot Web Application

An AI-powered chatbot web application built with **Next.js**, **React**, **Tailwind CSS**, **Supabase**, and **Google Gemini AI**. The application provides secure authentication, AI conversations, chat history, user settings, and a modern responsive interface.

---

## 📖 Overview

This project is a full-stack AI web application where users can:

- Create an account
- Login securely
- Chat with AI
- Save chat history
- Manage profile settings
- Reset passwords
- Access personalized dashboard
- Export Chat History

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/AI-Chatbot.git
```

Navigate to the project

```bash
cd AI-Chatbot
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file

```env
NEXT_PUBLIC_SUPABASE_URL=

NEXT_PUBLIC_SUPABASE_ANON_KEY=

GOOGLE_GEMINI_API_KEY=

GROQ_API_KEY=
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 🔑 Environment Variables

| Variable | Description |
|----------|-------------|
| NEXT_PUBLIC_SUPABASE_URL | Supabase Project URL |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | Supabase Public Key |
| GOOGLE_GEMINI_API_KEY | Google Gemini API Key |
| GROQ_API_KEY | Groq API Key |
